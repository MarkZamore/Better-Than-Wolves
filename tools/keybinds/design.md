# Управление Better Than Wolves

Пресет возвращает 18 штатных назначений Minecraft 1.6.4, BTW CE 3.1.1 и Nightmare Mode 1.1.6. Формат строк совпадает с `options.txt` этого клиента: целые коды LWJGL 2, включая −100/−99/−98 для ЛКМ/ПКМ/СКМ. Все 18 назначенных физических клавиш и кнопок различны.

| Контекст | Назначения |
|---|---|
| Движение и действия | WASD, Space, левый Shift, ЛКМ/ПКМ/СКМ, Q |
| Интерфейс Minecraft | E — инвентарь, T — чат, Tab — список игроков, / — команда |
| BTW CE | Левый Ctrl — Alternative Use, L — достижения |
| Nightmare Mode | C — зум при удержании, V — переключение зума |

Зум Nightmare действует в игровом окне без открытого GUI. При активном переключаемом зуме удержание V передаёт прокрутку настройке масштаба по штатным правилам Nightmare. C сохраняет авторское назначение даже при наличии отдельной диагностической комбинации F3+C. Клавиши панели 1–9, F1/F2/F5/F8/F11 и клавиши отладки обрабатываются клиентом отдельно и не входят в сохраняемый реестр.

Встроенный EMI хранит свои комбинации в `config/emi.css`. Просмотр рецептов R, применений U, избранное A и сочетания с Ctrl работают в его интерфейсе. Эти настройки остаются в распоряжении игрока.

## Проверка и обновление

Названия и значения сопоставлены с двумя снимками, записанными полным клиентом: исходный запуск и production `production-rename-09` с pack-owned bridge и управляемым транспортом. Контексты подтверждены по байткоду закреплённых Minecraft, CE и Nightmare. Проверка сопоставляет SHA256 четырёх активных игровых JAR с просмотренными версиями. При смене платформы или состава нужно повторно снять реестр из настоящего клиента и проверить контексты.

```text
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py --options <native-options.txt>
```

Пресет входит в обязательный слой как `launcher/controls-preset.txt`. После изменения обновите receipt и distribution lock через pack pipeline. Для намеренного удаления уберите запись из overlay, сам файл и вызов проверки в workflow, затем обновите receipt и lock.

Лаунчер получает файл вместе с проверенным `pack-latest`. Если назначение отличается, игрок может нажать кнопку пресета и подтвердить применение. Лаунчер меняет соответствующие строки `key_` личного `options.txt`. Пресет не заявляет владение этим файлом в `launcher/pack-owned.txt`.
